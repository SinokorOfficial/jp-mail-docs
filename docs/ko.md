# SANEI 메일 자동처리 — 화면 사용법

부킹 의뢰·S/R(선적서류)·위험물 서류 메일을 AI가 읽어내고, 담당자가 **확인하고 확정**하는 화면입니다.
이 문서는 "화면에서 무엇을 보고, 무엇을 누르는가"만 설명합니다. 日本語版は [こちら](index.md)。

!!! note "지금 무엇이 자동이고 무엇이 수동인가"
    - **자동**: 메일 수신 → 종류 판정 → 내용 읽기 → 확인 목록에 표시
    - **수동(담당자)**: 읽어낸 값 확인과 **[확정]**
    - **저장**: 현재는 테스트 운영이라 확정해도 ULOGI·포털에 **저장하지 않습니다**(화면 상단에 표시)

![로그인](img/01_login.png)

## 2. 처리 현황 (메인 화면)

![목록](img/02_list.png)

받은 메일이 **최신순**으로 놓입니다. 1행 = 메일 1통.

| 열 | 뜻 |
|---|---|
| 받은 시간 | 메일이 도착한 시각 (부킹일은 이 날짜가 됩니다) |
| 보낸 곳 | 발신자 |
| 제목·읽어낸 내용 | 위는 제목, 아래는 AI 요약(화주 → 수하인 · 출발항 → 도착항 · 선박 · 개수/중량) |
| 종류 | 부킹 요청 / 선적 서류(S/R) / 위험물 서류 / 기타 |
| 진행 상황 | 아래 4가지 중 하나 |
| (맨 오른쪽) **[확정]** | 확인이 끝나면 누르는 버튼 (상태가 아닙니다) |

### 진행 상황 읽는 법

| 표시 | 뜻 | 할 일 |
|---|---|---|
| ● **이상 없음 · 확정만 하면 됨** | 필요한 값이 다 있음 | 내용 보고 **[확정]** |
| ● **참고 N건 · 확인 후 확정** | 참고할 점 N건 | 오른쪽 "확인할 점" 보고 **[확정]** |
| ● **확인 필요 (빠진 값 있음)** | 화주·항구·일정 등 없으면 진행 못 하는 값이 빠짐 | 본문 확인 → 필요하면 수작업 |
| ● **업무 외 메일** | 부킹·S/R·위험물이 아닌 메일(문의·자동응답 등) | 할 일 없음 |

### 상단 탭과 검색

- **전체 / 확인 필요 / 참고 있음 / 이상 없음 / 처리 중 / 확정 / 업무 외** — 건수 표시, 누르면 목록이 걸러집니다
- 검색 — 보낸 곳·제목·부킹번호·화주
- **[필터 더 보기]** — 종류·기간, 목록 CSV 내려받기
- 여러 행 체크 → **[일괄 확정]**. 키보드 ↑↓ 이동, Enter 확정

## 3. 오른쪽 읽기 패널

![읽기 패널](img/03_pane_summary.png)

| 탭 | 내용 |
|---|---|
| **요약** | 확인할 점 + AI가 읽어낸 값(화주·수하인·출발/도착항·선박·항차·출항일·개수·중량·용적·운임조건·UN번호) |
| **자세히** | 종류 판단 이유, 첨부 파일명, 입력될 곳(ULOGI 부킹 화면 등), 걸린 시간, 처리 기록 |
| **입력값** | 시스템에 그대로 들어갈 값(ULOGI 항목명) |
| **원문·첨부 N** | 메일 원문(서식 그대로)과 첨부. **원본 서류와 읽어낸 값을 대조**하는 탭 |

!!! tip "확인할 점에 뜨는 것"
    "Shipper 없음" "출발/도착 항구 불명" "선명/항차·ETD 모두 없음" "위험물인데 UN번호 없음" 네 가지만 **확인 필요(빨강)** 입니다.
    운임조건·중량이 비어도 시스템 저장에 지장이 없어 표시하지 않습니다.

## 4. 원문·첨부 뷰어

![첨부](img/04_attachments.png)

- 첫 항목 **✉️ 메일 원문** — HTML 서식·표·붙여넣은 이미지(스케줄 캡처 등)가 그대로 보입니다
- 이어서 첨부 파일. 누르면 그 자리에서 열립니다

![뷰어](img/05_viewer.png)

| 형식 | 표시 |
|---|---|
| PDF | 브라우저 내장 뷰어(확대·페이지 이동·검색) |
| Excel | 시트별 탭, 표로 읽기 |
| 이미지 | 그대로 표시 |
| 그 외 | 내려받기 |

← → 로 이전/다음 첨부, Esc 로 닫기. 오른쪽 위 **[내려받기]**. 원본 `.msg`도 여기서 받을 수 있습니다.

## 5. 위험물 (Special Cargo) 화면

상단 메뉴 **[위험물]**. SKR 포털 Special Cargo에 넣을 항목을 **포털 화면과 같은 배치**로 먼저 확인합니다.

![위험물](img/06_dg_portal.png)

- 목록은 "위험물 서류 메일"과 "부킹 메일의 위험품 신청서(첨부)에서 미리 뽑은 것(**부킹 첨부** 표시)" 둘 다
- **Sequence** 드롭다운으로 품목(SEQ) 전환 — 포털과 같은 SEQ 개념
- **빨간 "필수"** 칸 — 서류에 없어 담당자가 포털에서 채워야 하는 필수값(Certificate No. 등)
- **초록 테두리** — 자동 변환된 값(항구명→코드, TANK→T/C, NET 0→총중량)
- 오른쪽 위 **[포털 화면] / [항목 목록]** 표시 전환
- 현재는 **포털에 등록하지 않습니다**. **[엑셀]**로 내려받아 담당자가 포털에 입력합니다
  - 선택한 건·기간 전체를 **한 파일로 일괄**(SEQ 1건 = 1행) 또는 **건별 파일(zip)**
  - 엑셀 열 이름 = 포털 화면 항목명. 필수값 빈 칸은 주황색

## 6. 통계

상단 메뉴 **[통계]**. 오늘/7일/14일/30일 전환.

![통계](img/07_stats.png)

- **받은 메일** — `= 부킹 + S/R + 위험물 서류 + 업무 외` 내역 포함. 더하면 전체와 같습니다
- **AI가 읽는 데 걸린 시간** — 메일 도착 → 확인 목록
- **받은 메일 추세** — 일별
- 아래: 일별 처리량, 시간대별, 종류별, 자주 나온 확인할 점, 보낸 곳, 보관함 현황(보관 기간: 부킹/S/R/위험물 365일, 업무 외 90일)

## 7. 자주 묻는 질문

**Q. 목록에 없는 메일이 있다**
A. 30초마다 사서함을 확인합니다. 30초를 기다려도 안 뜨면 상단 접속 표시(● 실시간 연결됨)를 확인하세요.

**Q. 읽어낸 값이 틀렸다**
A. **원문·첨부** 탭으로 원본을 보고, **[확정]**을 누르지 말고 수작업으로 처리하세요. 틀린 내용을 IT 담당에게 알려주면 정확도 개선에 씁니다.

**Q. "업무 외"에 업무 메일이 들어갔다 / 부킹이 "업무 외"로 갔다**
A. 제목과 본문을 IT 담당에게 전달해 주세요. 판정 규칙을 고칩니다.

**Q. 확정을 눌렀는데 시스템에 안 들어갔다**
A. 현재는 테스트 운영이라 저장하지 않습니다(화면 상단 "저장하지 않습니다"). 운영 전환 후엔 확정과 동시에 ULOGI에 저장되고 부킹번호가 표시됩니다.
