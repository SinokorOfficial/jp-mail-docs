# SANEI メール自動処理 — 画面の使い方

ブッキング依頼・S/R（船積書類）・危険物書類・輸入 A/N のメールを AI が読み取り、担当者が **確認して確定する** ための画面です。
このページは「画面で何を見て、何を押すか」だけを説明します。

!!! note "何が自動で、何が手動か"
    - **自動**: メールの受信 → 種類の判定 → 内容の読み取り → 確認リストへの表示
    - **手動（担当者）**: 読み取った値の確認 → 間違いは画面で修正 → **[確定]**
    - **確定すると実際に保存されます**
        - ブッキング → ULOGI にブッキング保存、ブッキング番号が画面に表示
        - S/R → ULOGI の輸出 House B/L を保存
        - 輸入 A/N → ULOGI 輸入 House B/L の Co-Load Agent・Warehouse、Master B/L No.
        - 危険物 → ポータルが取り込めるよう自動で取込用テーブルへ登録（ポータル画面への反映はポータル担当部署が準備中）
    - 確定後は画面で修正できません。確定前に **入力値** タブで直してください

!!! warning "画面の写真は 2026-09 時点のものです"
    その後 **[確定]**・値の修正・輸入 A/N 画面が追加され、ボタンの位置や文言が写真と少し異なることがあります。本文が基準です。

## 1. ログイン

![ログイン](img/01_login.png)

- アカウントとパスワードは担当者に配布されたものを入力します。一度ログインすると 14 日間はそのまま使えます。右上 **[ログアウト]** で終了
- 右上の **[日本語] [한국어]** で画面の言語を切り替えます
- アカウントごとに担当業務が異なるため、表示されるメニューが違います
    - ブッキング・S/R・輸入 A/N 担当: **すべて / ブッキング / S/R / 輸入A/N / 統計**
    - 危険物担当（東京・興亜）: **危険物 / 統計**
- 他のアカウントの件は表示されません

## 2. 処理状況（メイン画面）

![一覧](img/02_list.png)

受信したメールが **新しい順** に並びます。1 行 = メール 1 通。1 通にブッキングと危険物書類が同送されている場合は両方の画面に出ます。

| 列 | 意味 |
|---|---|
| 受信時刻 | メールが届いた時刻（ブッキング日はこの日付になります） |
| 送信元 | 差出人 |
| 件名・読み取った内容 | 上段が件名、下段が AI の読み取り要約（荷主 → 荷受人・積地 → 揚地・本船・個数/重量）。**修正**・**新規依頼** の表示 |
| 種類 | ブッキング依頼 / 船積書類(S/R) / 危険物書類 / 輸入A/N / 業務外 |
| 進行状況 | 下表 |
| （右端）**[確定]** | 確認が終わったら押すボタン（状態ではありません） |

### 進行状況の見方

| 表示 | 意味 | すること |
|---|---|---|
| ● **問題なし・確定するだけ** | 必要な値が揃っています | 内容を見て **[確定]** |
| ● **注意 N 件・確認して確定** | 参考にしてほしい点が N 件 | 右の「確認事項」を見て **[確定]** |
| ● **要確認（不足あり）** | 荷主・港・日程など、無いと保存できない値が欠けています | 本文を見て **入力値** タブで値を入れてから **[確定]** |
| ● **確定済み · ULOGI 保存済み · 番号** | 保存完了。ブッキングはブッキング番号、S/R は House B/L 番号 | なし（画面ではもう修正できません） |
| ● **業務外メール** | ブッキング・S/R・危険物・A/N ではないメール（問い合わせ・自動返信など） | 何もしなくてよい |
| ● **エラー** | 書類を読み取れませんでした | 行の **[再処理]**、または IT 担当へ |

### 上部のタブ・検索・ボタン

- **すべて / 要確認 / 注意あり / 問題なし / 処理中 / 確定 / 業務外** — 件数付き。押すと一覧が絞られます
- 検索欄 — 送信元・件名・ブッキング番号・荷主で絞り込み
- **[フィルターを開く]** — 種類・期間の絞り込み、一覧の CSV ダウンロード
- **[メールファイルを追加 (.msg/.eml)]** — メールボックスを経由しないメールを直接追加します。画面へのドラッグ＆ドロップも可。追加済みのメールは重複として除外されます
- 複数の行にチェック → **[選択した N 件を確定]** / **[選択した N 件を削除]**。キーボード ↑↓ で移動、Enter で確定

### [確定] を押すと

1. **必須項目が抜けていると**「それでも確定しますか？」の確認 — そのまま確定すると、抜けた値は ULOGI で担当者が直接入力することになります。通常は **[キャンセル]** して入力値タブで値を入れ、再度確定します
2. **同じ荷主・本船・日程で貨物（CBM・重量・個数・品目）まで同じブッキングが既にあると** 重複の確認 — 実荷主が異なる別のブッキングなら **[OK]**（新しい番号を採番）、同じブッキングなら **[キャンセル]**
3. 保存されると進行状況が **確定済み · ULOGI 保存済み · 番号** に変わります
4. **保存に失敗** と出た場合、その件は確定されずそのまま残ります。理由を見てもう一度確定するか、ULOGI に直接入力してください

!!! note "出港日（ETD）・積出港（POL）が無いと保存されません"
    ULOGI はこの 2 つからブッキング番号を採番します。入力値タブで入れてから確定してください。

### 削除・再処理

- **[削除]** — 一覧・添付の保管・統計から消え、元に戻せません。ULOGI に **保存済みの件は削除できません**（履歴保持）。ULOGI のデータは変わりません
- **[再処理]** — 今の件を消し、メールボックスから原文を取り直して最初から処理します（読み取りに失敗した件に使います）

## 3. 右側の読み取りパネル

一覧の行を押すと右側に詳細が出ます。

![読み取りパネル](img/03_pane_summary.png)

| タブ | 内容 |
|---|---|
| **概要** | 確認事項 + AI が読み取った値（荷主・荷受人・積地・揚地・本船・航次・出港日・個数・重量・容積・運賃条件・UN 番号） |
| **詳細** | 種類の判定理由、添付ファイル名、入力される先（ULOGI ブッキング画面など）、読み取りにかかった時間、処理履歴 |
| **入力値** | ULOGI にそのまま入力される値（ULOGI の項目名）。**ここで値を修正します** |
| **本文・添付 N** | メール本文（書式そのまま）と添付ファイル。**元の書類と読み取り値を突き合わせる** ためのタブ |

### 値の修正（入力値タブ）

1. **[✎ 値を修正]** → 直したい欄に入力（修正した欄は色が変わり「元: …」が並んで表示されます）
2. **[保存]** → 確認事項が再計算されます（例: 荷主を入れると「荷主がありません」が消える）
3. そのうえで **[確定]**
- **[最初の値に戻す]** — 修正をすべて破棄して最初に読み取った値に戻します
- 確定待ち・要確認の状態でのみ修正でき、**ULOGI に保存済みの件はロックされます**
- 修正内容は記録され、読み取り精度の改善に使います。ULOGI で直接直すと記録が残らないため、できるだけここで直してから確定してください

!!! tip "確認事項に出るもの"
    **要確認（赤）** になるのは保存を妨げるものだけ — 「荷主がありません」「積地／揚地が不明です」「本船・出港日が両方ありません」「UN番号がありません」、
    および読み取った取引先名がシステムの取引先と **似ているが異なる** 場合（「同じ会社か確認が必要」）。
    運賃条件や重量が空でも保存には支障がないため、参考としてのみ表示します。

## 4. 本文・添付ビューア

![添付](img/04_attachments.png)

- 最初の項目 **✉️ メール本文** — HTML の書式・表・貼り付け画像（スケジュール表など）がそのまま表示されます
- 続けて添付ファイル。押すとその場で開きます

![ビューア](img/05_viewer.png)

| 形式 | 表示 |
|---|---|
| PDF | ブラウザ内蔵ビューア（拡大・ページ移動・検索） |
| Excel | シートごとにタブ表示。表として読めます |
| 画像 | そのまま表示 |
| その他 | ダウンロード |

← → キーで前後の添付へ、Esc で閉じます。右上 **[ダウンロード]** で保存。原本 `.msg` もここから取れます。

## 5. 危険物（Special Cargo）画面

上部メニュー **[危険物]**。SKR ポータル Special Cargo に入る項目を **ポータル画面と同じ並び** で確認し、**確定** します。

![危険物](img/06_dg_portal.png)

- 一覧は「危険物書類のメール」と「ブッキング・S/R メールに同送された危険品書類（**ブッキングメールに同送 / S/R メールに同送** の表示）」の両方。過去の件も保管庫に残っている間は表示されます
- **Sequence** のプルダウンで品目（SEQ）を切り替え。SEQ はブッキング番号ごとに 1 から
- **赤い「必須」** の欄 — ポータル必須項目なのに書類に無いもの: Booking No.・UN CODE・Class No(IMDG)・SUB RISK・Packing GROUP・Container No.
- **緑の枠** — 自動変換した値（港名 → コード、TANK → T/C、NET 0 → 総重量 など）。**自動補正** の内容が下に書かれます
- 右上 **[ポータル画面] / [項目リスト]** で表示形式を切り替え。値をクリックするとコピーされます
- 興亜（HASL）の LCL 件は **ブッキング番号なしで進行** と表示されます

### 確定

- **[確定]** は危険物書類メールの件にだけあります（ブッキング・S/R に同送の危険物はそのメールの画面で確定）
- 必須項目が抜けていると「それでも確定しますか？」 — そのまま確定すると、ポータルでは担当者が直接入力することになります
- 確定した件は **確定済み**（確定した人・時刻）になり、1 分以内にポータルが取り込める形で登録されます。**確定後は修正できません**
- 複数の件にチェック → **[選択した N 件を確定]**
- **30 日を超えた件は確定できません**（「N 日超 · 確定不可」）

### 値の修正

- 欄を **ダブルクリック** で修正 → **[保存]** / **[元に戻す]**。コンテナ行の追加・削除もできます
- 確定待ち・要確認の状態でのみ。ブッキング・S/R メールに同送の危険物はそのメールの画面で修正します

### Excel

- **[Excel]** — 件別ファイル。チェックした件を **1 ファイルに一括**（SEQ 1 件 = 1 行）または **件別ファイル(zip)**
- 列名 = ポータル画面の項目名。必須項目の空欄はオレンジ。シート 3 枚 = Special Cargo・Containers・メール情報

### 問題発生

- 書類を読み取れなかったメールは一覧の上の **「問題発生 N 件」** 帯に別途表示 → **[再処理]**。直接アップロードしたファイルは削除して再アップロードします

## 6. 輸入 A/N 画面

上部メニュー **[輸入A/N]**。CO-LOADER から届いた到着案内（A/N）を読み取り、**登録済みの輸入 House B/L** に Master B/L No.・Co-Load Agent・Warehouse を入れます。

- 取り込み方 — どちらか
    1. A/N メールを添付ファイルごとメールボックスへ転送 → 1 分ほどでこの画面に出ます
    2. **[A/N をアップロード (PDF・画像)]** または画面へドラッグ＆ドロップ（PDF・画像のみ。本文やテキストに書かれた A/N は読みません）
- 一覧: 受付時刻・ファイル・B/L 番号・搬入倉庫・対象 House B/L・進捗
- 右側: **読み取った内容**（B/L 番号・船社 B/L・発行会社・搬入倉庫・NACCS・搬入確認番号・揚地・本船/航次・ETA・為替レート・コンテナ）、**ULOGI に入れる値**（House B/L・Master B/L No.・Co-Load Agent・Warehouse）、**確認事項**
- 間違いは **[修正]** → 欄を直す → **[保存]**（確定前のみ）
- **[確定]** → ULOGI に反映されます。確認事項が残っていると「それでも確定しますか？」が出ます
- **要確認** で止まるケース: 発行会社が CO-LOADER リストに無い / 搬入倉庫を読み取れない / ULOGI で対象の House B/L が見つからない。CO-LOAD の件でない（パートナー直送）か、House B/L が未登録の場合です。House B/L を登録してから同じファイルを再アップロードすると再検索します

## 7. 統計

上部メニュー **[統計]**。本日/7 日/14 日/30 日で切り替え。1 分ごとに自動更新。

![統計](img/07_stats.png)

- **受信メール** — `= ブッキング + S/R + 危険物書類 + 業務外`。足すと合計になります
- **AI の読み取り時間** — メール到着 → 確認リスト
- **確定までの待ち時間** — 確認リスト → 担当者確定（中央値）
- **受信メールの推移** — 日別
- 下段のタブ: 日別処理量、本日の時間帯別、種類別、送信元、保管庫（保管期間はブッキング/S/R/危険物 365 日、業務外 90 日）

## 8. よくある質問

**Q. 一覧に無いメールがある**
A. 30 秒ごとにメールボックスを確認しています。30 秒待っても出ない場合は上部の接続表示（● リアルタイム接続中）を確認してください。他のアカウント担当の件は表示されません。

**Q. 読み取った値が間違っている**
A. 確定前なら **入力値** タブの **[✎ 値を修正]** で直して **[保存]** → **[確定]**。修正内容は記録され、精度改善に使います。

**Q. 確定を押したのに ULOGI に入っていない**
A. 進行状況が **確定済み · ULOGI 保存済み · 番号** になっているか見てください。**保存に失敗** と出た場合は確定されていません。理由を見てもう一度確定するか直接入力し、繰り返すなら IT 担当へ連絡してください。

**Q. 確定した後に間違いに気づいた**
A. 画面では修正できません。ULOGI で直し、IT 担当に知らせてください。

**Q. 「業務外」に業務メールが入っている / 逆にブッキングが「業務外」になっている**
A. 件名と本文を IT 担当へ転送してください。判定ルールを直します。

**Q. 危険物の件に [確定] が無い**
A. ブッキング・S/R メールに同送された危険物か、30 日を超えた件です。前者はそのメールの画面で確定します。
