# SANEI メール自動処理 — 画面の使い方

ブッキング依頼・S/R（船積書類）・危険物書類のメールを AI が読み取り、担当者が **確認して確定する** ための画面です。
このページは「画面で何を見て、何を押すか」だけを説明します。

!!! note "いま何が自動で、何が手動か"
    - **自動**: メールの受信 → 種類の判定 → 内容の読み取り → 確認リストへの表示
    - **手動（担当者）**: 読み取った値の確認と **[確定]**
    - **保存**: 現在はテスト運用のため、確定しても ULOGI・ポータルには **保存しません**（画面上部に表示）

---

## 1. ログイン

![ログイン](img/01_login.png)

- アカウントとパスワードは担当者に配布されたものを入力します
- 一度ログインすると 14 日間はそのまま使えます。右上 **[ログアウト]** で終了

## 2. 処理状況（メイン画面）

![一覧](img/02_list.png)

受信したメールが **新しい順** に並びます。1 行 = メール 1 通。

| 列 | 意味 |
|---|---|
| 受信時刻 | メールが届いた時刻（ブッキング日はこの日付になります） |
| 送信元 | 差出人 |
| 件名・読み取った内容 | 上段が件名、下段が AI の読み取り要約（荷主 → 荷受人・積地 → 揚地・本船・個数/重量） |
| 種類 | ブッキング依頼 / 船積書類(S/R) / 危険物書類 / その他 |
| 進行状況 | 下表の 4 つのうち 1 つ |
| （右端）**[確定]** | 確認が終わったら押すボタン（状態ではありません） |

### 進行状況の見方

| 表示 | 意味 | すること |
|---|---|---|
| ● **問題なし・確定するだけ** | 必要な値が揃っています | 内容を見て **[確定]** |
| ● **注意 N 件・確認して確定** | 参考にしてほしい点が N 件 | 右の「確認事項」を見て **[確定]** |
| ● **要確認（不足あり）** | 荷主・港・日程など、無いと進めない値が欠けています | メール本文を見て値を確認 → 必要なら手作業 |
| ● **業務外メール** | ブッキング・S/R・危険物ではないメール（問い合わせ・自動返信など） | 何もしなくてよい |

### 上部のタブと検索

- **すべて / 要確認 / 注意あり / 問題なし / 処理中 / 確定 / 業務外** — 件数付き。押すと一覧が絞られます
- 検索欄 — 送信元・件名・ブッキング番号・荷主で絞り込み
- **[フィルターを開く]** — 種類・期間の絞り込み、一覧の CSV ダウンロード
- 複数の行にチェックを入れて **[一括確定]** も可能。キーボード ↑↓ で移動、Enter で確定

## 3. 右側の読み取りパネル

一覧の行を押すと右側に詳細が出ます。

![読み取りパネル](img/03_pane_summary.png)

| タブ | 内容 |
|---|---|
| **概要** | 確認事項 + AI が読み取った値（荷主・荷受人・積地・揚地・本船・航次・出港日・個数・重量・容積・運賃条件・UN 番号） |
| **詳細** | 種類の判定理由、添付ファイル名、入力される先（ULOGI ブッキング画面など）、読み取りにかかった時間、処理履歴 |
| **入力値** | システムにそのまま入力される値（ULOGI の項目名） |
| **本文・添付 N** | メール本文（書式そのまま）と添付ファイル。**元の書類と読み取り値を突き合わせる** ためのタブ |

!!! tip "確認事項に出るもの"
    「荷主がありません」「積地／揚地が不明」「本船・出港日がいずれもありません」「危険物ですが UN 番号がありません」の 4 つだけが **要確認（赤）** になります。
    運賃条件や重量が空でもシステム保存には支障がないため、表示しません。

## 4. 本文・添付ビューア

![添付](img/04_attachments.png)

- 最初の項目 **✉️ メール本文** — HTML の書式・表・貼り付け画像（スケジュール表など）がそのまま表示されます
- 続けて添付ファイル。押すとその場で開きます

![ビューア](img/05_viewer.png)

| 形式 | 表示 |
|---|---|
| PDF | ブラウザ内蔵ビューア（拡大・ページ移動・検索） |
| Excel | シートごとにタブ表示。表として読めます |
| 画像 | そのまま表示 |
| その他 | ダウンロード |

← → キーで前後の添付へ、Esc で閉じます。右上 **[ダウンロード]** で保存。原本 `.msg` もここから取れます。

## 5. 危険物（Special Cargo）画面

上部メニュー **[危険物]**。SKR ポータル Special Cargo に入力する項目を、**ポータル画面と同じ並び** で先に確認できます。

![危険物](img/06_dg_portal.png)

- 一覧は「危険物書類のメール」と「ブッキングメールの危険品申請書（添付）から先に抽出したもの（**ブッキング添付** 表示）」の両方
- **Sequence** のプルダウンで品目（SEQ）を切り替え。ポータルと同じ SEQ の考え方です
- **赤い「必須」** の枠 — 書類に無く、担当者がポータルで入力する必須項目（Certificate No. など）
- **緑の枠** — 自動変換した値（港名 → コード、TANK → T/C、NET 0 → 総重量）
- 右上 **[ポータル画面] / [項目リスト]** で表示形式を切り替え
- 現在は **ポータルへ登録しません**。**[Excel]** でダウンロードし、担当者がポータルに入力します
  - 選択した件・期間全体を **1 ファイルに一括**（SEQ 1 件 = 1 行）、または **件別ファイル(zip)** も可能
  - Excel はポータル画面の項目名がそのまま列。必須項目の空欄はオレンジ

## 6. 統計

上部メニュー **[統計]**。今日/7 日/14 日/30 日で切り替え。

![統計](img/07_stats.png)

- **受信メール** — `= ブッキング + S/R + 危険物書類 + 業務外` の内訳付き。足すと合計になります
- **AI が読むのにかかった時間** — メール到着 → 確認リストまで
- **受信メールの推移** — 日別
- 下段: 日別処理量、時間帯別、種類別、送信元、保管庫の状況（保管期間はブッキング/S/R/危険物 365 日、業務外 90 日）

## 7. よくある質問

**Q. 一覧に無いメールがある**
A. 30 秒ごとにメールボックスを確認しています。30 秒待っても出ない場合は上部の接続表示（● リアルタイム接続中）を確認してください。

**Q. 読み取った値が間違っている**
A. **本文・添付** タブで原本を見て、**[確定]** を押さずにそのまま手作業で処理してください。間違いの内容を IT 担当に伝えると精度改善に使います。

**Q. 「業務外」に業務メールが入っている / 逆にブッキングが「業務外」になっている**
A. 件名と本文を IT 担当へ転送してください。判定ルールを直します。

**Q. 確定を押したのにシステムに入っていない**
A. 現在はテスト運用のため保存を行いません（画面上部に「保存しません」と表示）。本番切替後は確定と同時に ULOGI に保存され、ブッキング番号が表示されます。
